# C2DP Web

Simple Next.js + Tailwind CSS 4 frontend for the C2DP Go API.

## Setup

```sh
cp .env.example .env.local
npm install
npm run dev
```

The app runs on `http://localhost:3000` and expects the API at `http://localhost:8080`.

## Environment

```sh
NEXT_PUBLIC_API_URL=http://localhost:8080
```
